# 抖音火花助手

抖音火花助手是一个功能强大的 Tampermonkey 用户脚本，专为抖音创作者后台设计，用于自动化管理和续订聊天火花。它提供智能聊天对象管理、个性化消息模板、宏系统以及定时发送等高级功能。

## 功能特性

### 核心功能

- **自动抓取聊天列表** - 一键将聊天对象抓取到暂存区
- **续火花目标管理** - 将重要聊天对象添加为续火花目标
- **个性化模板系统** - 为每个目标设置独立的消息模板
- **智能宏系统** - 支持自定义 JavaScript 代码扩展功能
- **定时发送** - 设置每日定时任务自动发送消息
- **批量发送** - 支持选中多个对象批量发送消息

### 高级特性

- **头像显示** - 自动抓取并显示聊天对象头像
- **聊天类型识别** - 自动识别朋友、群聊、陌生人消息
- **主题切换** - 支持亮色/暗色主题，跟随系统
- **响应式设计** - 适配各种屏幕尺寸
- **数据持久化** - 自动保存所有配置和数据
- **Monaco 编辑器** - 专业代码编辑体验，支持语法高亮和自动补全

### 用户体验

- **可拖拽面板** - 界面位置、大小可自由调整
- **快速操作** - 一键全选、批量操作
- **通知提醒** - 操作结果实时反馈
- **状态追踪** - 记录每个目标的上次发送时间

## 安装方法

5. 访问抖音创作者中心聊天页面

#### ScriptCat 安装

1. 安装 [ScriptCat](https://github.com/scriptscat/scriptcat)
2. 导入脚本文件
3. 访问抖音创作者中心

## 模板变量参考

### 内置变量（系统变量）

系统内置变量是预定义的变量，不可修改，但可以在模板中直接使用。

| 变量 | 类型 | 说明 | 代码实现 | 示例 |
|------|------|------|----------|------|
| `$date` | 变量 | 当前日期 | `new Date().toLocaleDateString()` | `2026/01/15` |
| `$targetName` | 变量 | 目标名称 | `targetName`（上下文变量） | `张三` |
| `$sinceDate("日期")` | 函数 | 计算从指定日期到现在的天数 | `function(dateStr) { ... }` | `$sinceDate("2026-01-01")` → `15` |

#### 内置变量详解

**1. `$date` - 当前日期**
- **类型**：变量（不需要参数）
- **实现代码**：`new Date().toLocaleDateString()`
- **说明**：获取当前日期，格式为 `YYYY/M/D`
- **使用示例**：
  ```javascript
  res = `今天是 $date`
  // 结果：今天是 2026/1/15
  ```

**2. `$targetName` - 目标名称**
- **类型**：变量（不需要参数）
- **实现代码**：`targetName`（从执行上下文中获取）
- **说明**：当前发送消息的目标联系人名称
- **使用示例**：
  ```javascript
  res = `嗨，$targetName！`
  // 结果：嗨，张三！
  ```

**3. `$sinceDate("日期")` - 相识天数**
- **类型**：函数（需要参数）
- **实现代码**：
  ```javascript
  function(dateStr) {
      try {
          const d = new Date(dateStr);
          if (isNaN(d)) return 0;
          const now = new Date();
          const diff = now - d;
          return Math.floor(diff / (1000 * 60 * 60 * 24));
      } catch (e) {
          return 0;
      }
  }
  ```
- **说明**：计算从指定日期到现在的天数差
- **参数**：日期字符串，格式为 `YYYY-MM-DD` 或 `YYYY/M/D`
- **使用示例**：
  ```javascript
  res = `我们已经成为好友$sinceDate("2026-01-01")天了！`
  // 结果：我们已经成为好友 15 天了！
  
  res = `相识$sinceDate("2025-12-01")天快乐！`
  // 结果：相识 46 天快乐！
  ```

### 变量系统说明

抖音火花助手使用强大的变量模板系统，支持动态内容和嵌套使用。

**变量分类**：
1. **内置变量**：系统提供，不可修改（`$date`、`$targetName`、`$sinceDate()`）
2. **自定义变量**：用户创建（通过变量管理面板）

**处理机制**：
- 支持最多 10 层嵌套
- 函数参数中的变量优先处理
- 自动检测循环引用并警告

### 变量使用方式

#### 1. 直接在模板中使用变量

最简单的方式是直接在模板字符串中使用变量：

```javascript
res = `嗨，$targetName！
今天是 $date
继续我们的火花吧！`
```

#### 2. 使用变量拼接字符串

你也可以使用 JavaScript 字符串拼接：

```javascript
res = "你好，" + $targetName + "！\n今天是 " + $date + "\n加油！";
```

#### 3. 结合自定义变量

在变量管理中创建自定义变量后，可以在模板中使用：

```javascript
// 假设创建了自定义变量 $greeting = "早上好"
res = `$greeting，$targetName！
今天是 $date
我们已经成为好友$sinceDate("2026-01-01")天了！`
```

#### 4. 嵌套变量使用（高级）

系统支持变量和函数的嵌套使用：

```javascript
// 场景 1：函数参数使用变量
$formatDate($date)  // 结果：日期：2026/1/15

// 场景 2：多层嵌套
$repeat("$sinceDate('2026-01-01') + '天'", 1)  // 结果：15 天

// 场景 3：多参数嵌套
$createGreeting($targetName, $sinceDate("2026-01-01"))  // 结果：张三，我们相识 15 天快乐！
```

**处理顺序**：从内到外，先处理参数，再执行函数

### 自定义变量管理

#### 如何自定义一个变量（详细步骤）

**核心概念**

> 所有自定义值本质上都是代码片段，执行后得到结果。区别在于：
> - **变量**：不需要参数的代码，直接执行得到值
> - **函数**：需要接收参数的代码，调用时传入参数

**步骤 1：打开变量管理面板**

1. 在抖音火花助手面板顶部，点击"变量管理"按钮
2. 弹出变量管理对话框

**步骤 2：添加新变量**

1. 点击"添加变量"按钮
2. 弹出变量编辑窗口

**步骤 3：填写变量信息**

在变量编辑窗口中，填写以下信息：

- **变量名**：输入变量名（例如：`greeting`）
  - 只能包含字母、数字和下划线
  - 必须以字母或下划线开头
  - 示例：`greeting`、`my_var`、`emoji123` ✅
  - 错误示例：`123var`、`my-var`、`hello world` ❌

- **类型**：选择变量类型
  - **变量**：不需要参数的代码片段，直接执行得到值
  - **函数**：需要接收参数的函数，调用时传入参数

- **值/代码**：输入 JavaScript 代码
  - 使用 Monaco 代码编辑器，支持语法高亮和自动补全
  - **变量类型**：输入任何 JavaScript 表达式，如 `"早上好"`、`100`、`"🔥"`
  - **函数类型**：输入完整的函数定义，如 `function(param) { return param; }`

- **描述**（可选）：说明变量的用途
  - 例如：`用于问候语的前缀`

**步骤 4：保存变量**

1. 点击"保存"按钮
2. 变量会出现在变量列表中

**步骤 5：使用变量**

在模板中使用自定义变量：

```javascript
// 模板示例
res = `$greeting，$targetName！
今天是 $date
加油！`
```

#### 变量和函数的本质

| 类型 | 本质 | 使用方式 | 示例 |
|------|------|----------|------|
| **变量** | 不需要参数的代码片段 | `$varName` | `$greeting` |

**重要**：所有值都是通过执行 JavaScript 代码得到的！

#### 变量类型示例

**示例 1：简单字符串**
```javascript
// 值/代码："早上好"
// 使用：$greeting
// 结果：早上好
```

**示例 2：数值计算**
```javascript
// 值/代码：100 + 50
// 使用：$total
// 结果：150
```

**示例 3：数组操作**
```javascript
// 值/代码：['🔥', '❤️', '✨'].join('')
// 使用：$emojis
// 结果：🔥❤️✨
```

**示例 4：日期格式化**
```javascript
// 值/代码：new Date().toLocaleDateString('zh-CN')
// 使用：$today
// 结果：2026 年 1 月 15 日
```

**示例 5：随机值**
```javascript
// 值/代码：Math.floor(Math.random() * 100)

```

#### 函数类型示例

**示例 1：无参数函数**
```javascript
function() {
    return "你好";
}
// 使用：$sayHi()
// 结果：你好
```

**示例 2：单参数函数**
```javascript
function(name) {
    return "你好，" + name;
}
// 使用：$greet("张三")
// 结果：你好，张三
```

**示例 3：多参数函数**

    return str.repeat(times);

```

**示例 4：带默认参数**

    return "早上好，" + name;
}
// 使用：$greet() 或 $greet("张三")
// 结果：早上好，朋友 或 早上好，张三
```

### 嵌套变量处理

**处理机制**：
- 最多支持 10 层嵌套
- 函数参数中的变量优先处理
- 自动检测循环引用并警告

**示例流程**：`$createMessage($targetName, $sinceDate("2026-01-01"))`
```
第 1 轮：$targetName → "张三"，$sinceDate("2026-01-01") → 15
第 2 轮：$createMessage("张三", 15) → "张三，我们相识 15 天了！"
第 3 轮：处理结束
```

**注意事项**：

⚠️ **避免循环引用**
```javascript
// ❌ 错误：循环引用
$varA = $varB + "1"
$varB = $varA + "2"

// ✅ 正确：单向依赖
$greeting = "亲爱的"
$message = greeting + "朋友"  // 不加 $
```

⚠️ **变量内引用：不加 $**
```javascript
// ❌ 错误
$fullGreeting = "$greeting" + "朋友"

// ✅ 正确
$fullGreeting = greeting + "朋友"
```

⚠️ **模板中使用：必须加 $**
```javascript
// ✅ 正确
res = `$fullGreeting，$targetName！`
```

⚠️ **函数参数的引号**
```javascript
// ✅ 正确
$repeat("🔥", 3)
$sinceDate("2026-01-01")

// ❌ 错误
$repeat(🔥, 3)
```

### 最佳实践

#### 1. 使用有意义的变量名

```javascript
// ✅ 好的命名
$greeting = "早上好"
$emoji = "🔥"
$blessing = "愿友谊长存"

// ❌ 避免使用
$a = "早上好"
$b = "🔥"
```

#### 2. 合理组织变量

将相关的变量组织在一起，便于管理：

```javascript
// 问候相关
$greeting_morning = "早上好"
$greeting_afternoon = "下午好"
$greeting_evening = "晚上好"

// 表情符号
$emoji_fire = "🔥"
$emoji_heart = "❤️"
$emoji_sun = "☀️"
```

#### 3. 在宏中使用变量

宏可以读取和修改变量，实现更复杂的逻辑：

```javascript
// 宏示例：根据时间自动选择问候语
const hour = new Date().getHours();
if (hour < 12) {
    $greeting = "早上好";
} else if (hour < 18) {
    $greeting = "下午好";
} else {
    $greeting = "晚上好";
}

res = `$greeting，$targetName！`;
```

#### 4. 变量复用

创建通用变量，在多个模板中复用：

```javascript
// 创建通用变量
$signature = "你的朋友 DouYinSpark"
$emoji = "✨"

// 在多个模板中使用
res = `消息内容...\n\n$signature$emoji`;
```

### 注意事项

1. **变量命名规则**：
   - 只能包含字母、数字和下划线
   - 不能以数字开头
   - 区分大小写

2. **内置变量不可修改**：
   - `$date`、`$targetName`、`$sinceDate()` 是系统内置变量
   - 不能创建与内置变量同名的自定义变量

3. **变量作用域**：
   - 自定义变量在所有模板中都可以使用
   - 宏中可以读取和修改变量

4. **性能考虑**：
   - 避免创建过多不必要的变量
   - 定期清理不再使用的变量

## 常见问题

### Q1: 脚本不工作怎么办？

**A:** 检查以下几点：
1. 确保已安装 Tampermonkey 并启用脚本
2. 确认访问的是抖音创作者后台（creator.douyin.com）
3. 刷新页面重试
4. 检查浏览器控制台是否有错误信息

### Q2: 无法抓取聊天列表？

**A:** 可能原因：
1. 页面结构发生变化 - 等待脚本更新
2. 网络延迟 - 稍后重试
3. 聊天列表未加载完成 - 等待页面完全加载

### Q3: 发送消息失败？

**A:** 检查：
1. 是否已登录抖音创作者后台
2. 发送间隔是否过短（建议 3 秒以上）
3. 目标对象是否已被删除或拉黑
4. 浏览器控制台是否有错误

### Q4: Monaco 编辑器无法加载？

**A:** 解决方案：
1. 检查网络连接
2. 清除浏览器缓存
3. 尝试切换 CDN 源（脚本会自动处理）
4. 检查浏览器是否阻止了外部资源加载

### Q5: 定时发送不生效？

**A:** 确认：
1. 已启用定时器（状态显示"运行中"）
2. 页面保持打开状态
3. 浏览器未进入休眠模式
4. 定时时间设置正确

### Q6: 群聊无法发送消息？

**A:** 脚本已支持群聊：
1. 确保群聊在聊天列表中
2. 脚本会自动识别群聊类型
3. 如仍有问题，检查群聊名称是否变化

### Q7: 如何更新脚本？

**A:** 
1. Tampermonkey 会自动检查更新
2. 手动更新：打开 Tampermonkey 面板 → 找到脚本 → 点击更新
3. 或重新安装最新版本

### Q8: 数据会丢失吗？

**A:** 
- 数据存储在浏览器本地，清除缓存会丢失
- 建议定期备份重要数据
- 脚本支持数据迁移，升级不会丢失数据
